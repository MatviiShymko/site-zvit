Pn(x) = ∑i=0n aixn-i,    Pm(x) = ∑i=0m bixm-i

Значення деяких коефіцієнтів можуть дорівнювати нулю. Визначити і вивести на екран вирази, що є часткою та остачею від ділення одного многочлена на інший. Здійснити перевірку результату ділення многочленів, визначивши добуток частки на многочлен-дільник з додаванням остачі.

Спільне для всіх завдань

Якщо введено не число або число поза межами, програма скидає помилку через cin.clear(), пропускає неправильний рядок через cin.ignore() і просить увести значення ще раз. Завдання 1 - варіант 6

Умова не каже, чи є серією один елемент. У програмі один елемент теж вважається серією, якщо сусідні елементи від нього відрізняються.

Лічильник довжини починається з 1 і збільшується, поки поточний елемент дорівнює попередньому. Коли елемент інший або масив закінчився, серія виводиться, її довжина порівнюється з найбільшою, а лічильник знову стає 1.

Цикл іде до i = n включно, щоб вивести й останню серію.

Псевдовипадкові числа беруться від 0 до 4, щоб траплялись однакові сусідні елементи.

Завдання 2 - варіант 6

Одна ітерація парно-непарного сортування складається з двох проходів. Перший порівнює пари (a0, a1), (a2, a3), ..., другий пари (a1, a2), (a3, a4), ... Якщо елементи пари стоять неправильно, вони міняються місцями. Сортування закінчується, коли за всю ітерацію не було жодного обміну. За одну ітерацію виконується n - 1 порівняння.

Обмін міняє місцями два сусідні елементи і виправляє одну пару, що стояла в неправильному порядку. Тому обмінів стільки, скільки таких пар у вхідному масиві.

Пошук у масиві з обертанням призначений для масиву, який після сортування зсунули по колу. В умові цього кроку немає, тому після сортування програма просить увести зсув k від 0 до n - 1 і зсуває масив вправо на k позицій. Елемент з індексом i переходить на місце, що дорівнює остачі від ділення i + k на n. Зсув виконується через допоміжний масив.

Сам пошук є зміненим двійковим пошуком. На відрізку [l, r] береться середина m. Якщо am дорівнює ключу, пошук закінчено. Інакше хоча б одна половина відрізка відсортована:

  • якщо al ≤ am, відсортована ліва половина. Якщо ключ лежить між al і am, пошук продовжується в ній, інакше у правій;
  • інакше відсортована права половина. Якщо ключ лежить між am і ar, пошук продовжується в ній, інакше у лівій.

Якщо al = am = ar, визначити відсортовану половину не можна, тому програма відкидає обидва краї: l збільшується, r зменшується.

У сортуванні рахуються всі порівняння двох елементів і всі обміни, у пошуку порівняння ключа із середнім елементом, тобто кроки пошуку. Користувач обирає режим виведення: лише результат або проміжні ітерації. У другому режимі програма друкує масив після кожного проходу сортування, а також межі й середину відрізка на кожному кроці пошуку.

Завдання 3 - варіант 6

Многочлени діляться стовпчиком. Коефіцієнти зберігаються від старшого до вільного члена, як у формулах умови. Діленим є Pm, бо його степінь більший. Степінь частки дорівнює m - n, а степінь остачі менший за n. На кроці i (від 0 до m - n):

qi = ri / a0,    ri+j = ri+j - qi · aj,   j = 0, 1, ..., n

Спочатку r дорівнює коефіцієнтам діленого. Після всіх кроків останні n значень r є коефіцієнтами остачі.

Для перевірки програма множить частку на дільник, додає остачу і порівнює коефіцієнти результату з коефіцієнтами Pm:

ci+j = ci+j + qi · aj

На a0 виконується ділення, тому він не може дорівнювати нулю. Під час введення нуль не приймається, а під час генерації a0 генерується знову, поки не стане відмінним від нуля. Нижня межа діапазону має бути меншою за верхню. Якщо справжній степінь діленого менший за n, частка дорівнює 0, а остача дорівнює діленому.

Коефіцієнти Pm і Pn цілі, від -100 до 100, а m не більше 8. Коефіцієнти частки й остачі дійсні. Для них обрано double, бо коефіцієнти частки швидко ростуть і точності float для перевірки не вистачає. Числа, менші за модулем від 10-6, вважаються нулем.

/////////////////////////////////////////////////////////////////////
// Ім'я файлу: task1.cpp
// Автор: Шимко Матвій, гр. ІПЗ-11(3)
// Номер версії модуля: version 1
// Запланована ціль: лабораторна робота №6, завдання 1, варіант 6.
//                   Знайти в цілочисельному масиві всі серії однакових
//                   елементів і довжину найдовшої серії.
/////////////////////////////////////////////////////////////////////

#include <cstdlib>
#include <ctime>
#include <iostream>
using namespace std;

//=========== константи
const int MAX_SIZE = 100;    // найбільша кількість елементів масиву
const int MIN_VALUE = -1000; // межі елемента, що вводиться з клавіатури
const int MAX_VALUE = 1000;
const int RANDOM_RANGE = 5; // випадкові числа від 0 до 4, щоб були повтори

//=========== глобальні змінні
int numbers[MAX_SIZE] = {0}; // масив
int elementCount = 0;        // кількість елементів масиву
int choice = 0;              // вибраний пункт меню
int seriesLength = 0;        // довжина поточної серії
int longestLength = 0;       // довжина найдовшої серії
int seriesCount = 0;         // кількість серій

/*
 * Функція виводить дані про автора та умову задачі
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void welcome()
{
    cout << "Lab work 6. Task 1. Variant 6." << endl;
    cout << "Author: Matvii Shimko, group IPZ-11(3)" << endl << endl;

    cout << "Find all series of equal elements standing in a row" << endl;
    cout << "and the length of the longest series." << endl << endl;
}

/*
 * Функція вводить ціле число. Якщо введено не число або число поза
 * межами, введення повторюється
 * Параметри: minValue, maxValue - межі допустимого значення
 * Значення, що повертаються: введене число
 */
int inputNumber(int minValue, int maxValue)
{
    int number = 0;

    cin >> number;
    while (cin.fail() || number < minValue || number > maxValue)
    {
        cin.clear();            // скинути помилку введення
        cin.ignore(1000, '\n'); // і пропустити неправильний рядок
        cout << "Error! Enter a number from " << minValue << " to " << maxValue
             << ": ";
        cin >> number;
    }

    return number;
}

/*
 * Функція вводить кількість елементів масиву
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void inputSize()
{
    cout << "Enter the number of elements (from 1 to " << MAX_SIZE << "): ";
    elementCount = inputNumber(1, MAX_SIZE);
}

/*
 * Функція вводить елементи масиву з клавіатури
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void inputArray()
{
    for (int i = 0; i < elementCount; i++)
    {
        cout << "Enter element " << i << ": ";
        numbers[i] = inputNumber(MIN_VALUE, MAX_VALUE);
    }
}

/*
 * Функція заповнює масив псевдовипадковими числами від 0 до 4
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void generateArray()
{
    srand(time(NULL));
    for (int i = 0; i < elementCount; i++)
    {
        numbers[i] = rand() % RANDOM_RANGE;
    }
}

/*
 * Функція виводить меню і створює масив вибраним способом
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void runMenu()
{
    cout << endl << "How to create the array:" << endl;
    cout << "1 - enter from the keyboard" << endl;
    cout << "2 - fill with pseudorandom numbers" << endl;
    cout << "Your choice: ";
    choice = inputNumber(1, 2);

    switch (choice)
    {
        case 1 : inputArray(); break;
        case 2 : generateArray(); break;
        default : cout << "There is no such menu item." << endl; break;
    }
}

/*
 * Функція виводить масив
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void printArray()
{
    cout << endl << "Array:";
    for (int i = 0; i < elementCount; i++)
    {
        cout << " " << numbers[i];
    }
    cout << endl;
}

/*
 * Функція виводить одну серію, що закінчується перед індексом endIndex
 * Параметри: endIndex - індекс елемента після серії
 * Значення, що повертаються: немає
 */
void printSeries(int endIndex)
{
    cout << "Series " << seriesCount << ":";
    for (int i = endIndex - seriesLength; i < endIndex; i++)
    {
        cout << " " << numbers[i];
    }
    cout << " (length " << seriesLength << ", starts at index "
         << endIndex - seriesLength << ")" << endl;
}

/*
 * Функція проходить масив, виводить усі серії і довжину найдовшої.
 * Серія закінчується, коли наступний елемент інший або масив закінчився
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void findSeries()
{
    cout << endl << "Series of equal elements:" << endl;

    seriesLength = 1;
    longestLength = 1;
    seriesCount = 0;

    for (int i = 1; i <= elementCount; i++)
    {
        if (i < elementCount && numbers[i] == numbers[i - 1])
        {
            seriesLength++;
        }
        else
        {
            seriesCount++;
            printSeries(i);
            if (seriesLength > longestLength)
            {
                longestLength = seriesLength;
            }
            seriesLength = 1;
        }
    }

    cout << endl << "Number of series: " << seriesCount << endl;
    cout << "Length of the longest series: " << longestLength << endl;
}

int main()
{
    welcome();
    inputSize();
    runMenu();
    printArray();
    findSeries();
    return 0;
}

#include <cstdlib>

#include <iostream>

//=========== константи
const int MAX_SIZE = 100;    // найбільша кількість елементів масиву
const int MIN_VALUE = -1000; // межі елемента, що вводиться з клавіатури
const int MAX_VALUE = 1000;
const int RANDOM_RANGE = 100; // випадкові числа від 0 до 99

//=========== глобальні змінні
int numbers[MAX_SIZE] = {0};        // масив
int shiftedNumbers[MAX_SIZE] = {0}; // допоміжний масив для зсуву
int elementCount = 0;               // кількість елементів масиву
int choice = 0;                     // вибраний пункт меню
bool isDetailed = false;            // чи виводити проміжні ітерації
bool isSorted = false;              // чи не було обмінів за ітерацію
int iteration = 0;                  // номер ітерації сортування
int comparisonCount = 0;            // кількість порівнянь у сортуванні
int swapCount = 0;                  // кількість обмінів у сортуванні
int shift = 0;                      // зсув вправо
int key = 0;                        // шукане значення
int leftIndex = 0;                  // ліва межа відрізка пошуку
int rightIndex = 0;                 // права межа відрізка пошуку
int middleIndex = 0;                // середина відрізка пошуку
int foundIndex = -1;                // індекс ключа, -1 якщо його немає
int searchCount = 0;                // кількість порівнянь із ключем

/*
 * Функція виводить дані про автора та умову задачі

/*
 * Функція вводить ціле число. Якщо введено не число або число поза

/*
 * Функція вводить кількість елементів масиву
 * Параметри: немає

/*
 * Функція вводить елементи масиву з клавіатури

/*
 * Функція заповнює масив псевдовипадковими числами від 0 до 99

void generateArray()
{
    srand(time(NULL));
    for (int i = 0; i < elementCount; i++)

        numbers[i] = rand() % RANDOM_RANGE;
    }
}

/*
 * Функція виводить меню і створює масив вибраним способом

    cout << "2 - with intermediate iterations" << endl;
    cout << "Your choice: ";
    choice = inputNumber(1, 2);
    if (choice == 2)

    }

/*
 * Функція виводить елементи масиву в один рядок
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void printArray()
{
    for (int i = 0; i < elementCount; i++)
    {
        cout << " " << numbers[i];
    }
    cout << endl;
}

/*
 * Функція порівнює пари сусідніх елементів, починаючи з firstIndex,
 * і міняє місцями ті, що стоять неправильно
 * Параметри: firstIndex - індекс першого елемента першої пари
 * Значення, що повертаються: немає
 */
void sortPairs(int firstIndex)
{
    int temporary = 0;

    for (int i = firstIndex; i < elementCount - 1; i = i + 2)
    {
        comparisonCount++;
        if (numbers[i] > numbers[i + 1])
        {
            temporary = numbers[i];
            numbers[i] = numbers[i + 1];
            numbers[i + 1] = temporary;
            swapCount++;
            isSorted = false;
        }
    }
}

/*
 * Функція сортує масив за зростанням. Кожна ітерація проходить пари
 * з парним першим індексом, потім з непарним. Сортування закінчується,
 * коли за ітерацію не було жодного обміну
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void sortArray()
{
    cout << endl << "Input array:";
    printArray();

    isSorted = false;
    while (!isSorted)
    {
        isSorted = true;
        iteration++;

        sortPairs(0);
        if (isDetailed)
        {
            cout << "Iteration " << iteration << ", even pairs:";
            printArray();
        }

        sortPairs(1);
        if (isDetailed)
        {
            cout << "Iteration " << iteration << ", odd pairs: ";
            printArray();
        }
    }

    cout << "Sorted array:";
    printArray();
    cout << "Iterations: " << iteration << endl;
    cout << "Comparisons: " << comparisonCount << endl;
    cout << "Swaps: " << swapCount << endl;
}

/*
 * Функція вводить зсув і циклічно зсуває масив вправо
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void rotateArray()
{
    cout << endl
         << "Enter the cyclic shift to the right (from 0 to "
         << elementCount - 1 << "): ";
    shift = inputNumber(0, elementCount - 1);

    for (int i = 0; i < elementCount; i++)
    {
        shiftedNumbers[(i + shift) % elementCount] = numbers[i];
    }

    for (int i = 0; i < elementCount; i++)
    {
        numbers[i] = shiftedNumbers[i];
    }

    cout << "Rotated array:";
    printArray();
}

/*
 * Функція шукає ключ у масиві з обертанням. На кожному кроці одна
 * половина відрізка відсортована: якщо ключ лежить у ній, пошук іде
 * там, інакше в другій половині. Якщо обидва краї дорівнюють
 * середньому елементу, половину визначити не можна, тому краї
 * відкидаються
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void searchKey()
{
    cout << endl << "Enter the key: ";
    key = inputNumber(MIN_VALUE, MAX_VALUE);

    leftIndex = 0;
    rightIndex = elementCount - 1;
    foundIndex = -1;

    while (leftIndex <= rightIndex && foundIndex == -1)
    {
        middleIndex = (leftIndex + rightIndex) / 2;
        searchCount++;

        if (isDetailed)
        {
            cout << "Step " << searchCount << ": left = " << leftIndex
                 << ", right = " << rightIndex << ", middle = " << middleIndex
                 << ", element = " << numbers[middleIndex] << endl;
        }

        if (numbers[middleIndex] == key)
        {
            foundIndex = middleIndex;
        }
        else if (numbers[leftIndex] == numbers[middleIndex]
                 && numbers[rightIndex] == numbers[middleIndex])
        {
            leftIndex++;
            rightIndex--;
        }
        else if (numbers[leftIndex] <= numbers[middleIndex])
        {
            if (numbers[leftIndex] <= key && key < numbers[middleIndex])
            {
                rightIndex = middleIndex - 1;
            }
            else
            {
                leftIndex = middleIndex + 1;
            }
        }
        else
        {
            if (numbers[middleIndex] < key && key <= numbers[rightIndex])
            {
                leftIndex = middleIndex + 1;
            }
            else
            {
                rightIndex = middleIndex - 1;
            }
        }
    }

    if (foundIndex == -1)
    {
        cout << "The key " << key << " is not in the array." << endl;
    }
    else
    {
        cout << "The key " << key << " is at index " << foundIndex << "."
             << endl;
    }
    cout << "Search comparisons: " << searchCount << endl;
}

int main()
{
    welcome();
    inputSize();
    runMenu();
    inputOutputMode();
    sortArray();
    rotateArray();
    searchKey();
    return 0;
}

//=========== глобальні змінні
// double, бо коефіцієнти частки швидко ростуть, і 7 цифр float не вистачає:

double workArray[MAX_DEGREE + 1] = {0};     // залишок під час ділення
double quotient[MAX_DEGREE + 1] = {0};      // коефіцієнти частки
double remainderPart[MAX_DEGREE + 1] = {0}; // коефіцієнти остачі
double checkResult[MAX_DEGREE + 1] = {0};   // частка * дільник + остача
int dividendDegree = 0;                     // степінь діленого m
int divisorDegree = 0;                      // степінь дільника n
int quotientDegree = 0;                     // степінь частки m - n
int lowerBound = 0;                         // межі випадкових коефіцієнтів
int upperBound = 0;
int choice = 0;        // вибраний пункт меню

/*

}

/*
 * Функція вводить ціле число. Якщо введено не число або число поза

/*
 * Функція вводить степені многочленів m і n, m > n > 2

    cout << "Enter degree n (from " << MIN_DEGREE << " to "
         << dividendDegree - 1 << "): ";
    divisorDegree = inputNumber(MIN_DEGREE, dividendDegree - 1);

    quotientDegree = dividendDegree - divisorDegree;
}

/*
 * Функція вводить коефіцієнти обох многочленів з клавіатури.

    cout << "a0 (at x^" << divisorDegree << "): ";
    divisor[0] = inputNumber(MIN_COEFFICIENT, MAX_COEFFICIENT);
    while (divisor[0] == 0)

    }

    for (int i = 1; i <= divisorDegree; i++)

/*
 * Функція вводить діапазон і заповнює коефіцієнти псевдовипадковими
 * цілими числами. Нижня межа менша за верхню, тому старший коефіцієнт
 * дільника рано чи пізно вийде відмінним від нуля

void generateCoefficients()

    upperBound = inputNumber(lowerBound + 1, MAX_COEFFICIENT);

    srand(time(NULL));
    for (int i = 0; i <= dividendDegree; i++)

        dividend[i] = rand() % (upperBound - lowerBound + 1) + lowerBound;

    for (int i = 0; i <= divisorDegree; i++)
    {
        divisor[i] = rand() % (upperBound - lowerBound + 1) + lowerBound;
    }

    while (divisor[0] == 0)
    {
        divisor[0] = rand() % (upperBound - lowerBound + 1) + lowerBound;
    }
}

/*
 * Функція виводить меню і створює коефіцієнти вибраним способом

/*
 * Функція виводить многочлен у вигляді виразу, нульові члени пропускає
 * Параметри: coefficients - коефіцієнти від старшого до вільного члена,
 *            degree - степінь многочлена
 * Значення, що повертаються: немає
 */
void printPolynomial(double coefficients[], int degree)
{
    bool isFirst = true; // чи ще не виведено жодного члена
    int power = 0;       // степінь x у поточному члені

    for (int i = 0; i <= degree; i++)
    {
        power = degree - i;
        if (fabs(coefficients[i]) > TOLERANCE)
        {
            if (coefficients[i] < 0 && isFirst)
            {
                cout << "-";
            }
            else if (coefficients[i] < 0)
            {
                cout << " - ";
            }
            else if (!isFirst)
            {
                cout << " + ";
            }

            cout << fabs(coefficients[i]);
            if (power > 0)
            {
                cout << "x";
            }
            if (power > 1)
            {
                cout << "^" << power;
            }
            isFirst = false;
        }
    }

    if (isFirst)
    {
        cout << "0";
    }
    cout << endl;
}

/*
 * Функція ділить многочлени стовпчиком. Кожен коефіцієнт частки це
 * старший коефіцієнт залишку, поділений на старший коефіцієнт дільника.
 * Від залишку віднімається дільник, помножений на цей коефіцієнт
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void dividePolynomials()
{
    for (int i = 0; i <= dividendDegree; i++)
    {
        workArray[i] = dividend[i];
    }

    for (int i = 0; i <= quotientDegree; i++)
    {
        quotient[i] = workArray[i] / divisor[0];
        for (int j = 0; j <= divisorDegree; j++)
        {
            workArray[i + j] = workArray[i + j] - quotient[i] * divisor[j];
        }
    }

    for (int i = 0; i < divisorDegree; i++)
    {
        remainderPart[i] = workArray[quotientDegree + 1 + i];
    }
}

/*
 * Функція множить частку на дільник, додає остачу і порівнює
 * результат із діленим
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void checkDivision()
{
    for (int i = 0; i <= dividendDegree; i++)
    {
        checkResult[i] = 0;
    }

    for (int i = 0; i <= quotientDegree; i++)
    {
        for (int j = 0; j <= divisorDegree; j++)
        {
            checkResult[i + j] = checkResult[i + j] + quotient[i] * divisor[j];
        }
    }

    for (int i = 0; i < divisorDegree; i++)
    {
        checkResult[quotientDegree + 1 + i] =
            checkResult[quotientDegree + 1 + i] + remainderPart[i];
    }

    isCorrect = true;
    for (int i = 0; i <= dividendDegree; i++)
    {
        if (fabs(checkResult[i] - dividend[i]) > TOLERANCE)
        {
            isCorrect = false;
        }
    }
}

/*
 * Функція виводить многочлени, частку, остачу і результат перевірки
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void printResults()
{
    cout << endl << "Pm(x) = ";
    printPolynomial(dividend, dividendDegree);
    cout << "Pn(x) = ";
    printPolynomial(divisor, divisorDegree);

    cout << endl << "Quotient  Q(x) = ";
    printPolynomial(quotient, quotientDegree);
    cout << "Remainder R(x) = ";
    printPolynomial(remainderPart, divisorDegree - 1);

    cout << endl << "Check: Q(x) * Pn(x) + R(x) = ";
    printPolynomial(checkResult, dividendDegree);

    if (isCorrect)
    {
        cout << "The result of the check is equal to Pm(x)." << endl;
    }
    else
    {
        cout << "The result of the check is NOT equal to Pm(x)." << endl;
    }
}

{
    welcome();

Завдання 3: перевірка в Excel і вручну

Сценарії 1 і 3 перевірено в Excel (файл check.xlsx, аркуш «Завдання 3»). Excel ділить многочлени своїми формулами: кожен рядок залишку обчислено з попереднього, а поруч стоять значення програми. Потім Excel множить частку на дільник і додає остачу. Частка, остача і результат перевірки збіглися в обох сценаріях.

Сценарій 1 перевірено ще й вручну. Частка x² - 2x + 2.5, дільник 2x³ + x² - 3x + 1:

(x² - 2x + 2.5)(2x³ + x² - 3x + 1) = 2x5 - 3x4 + 9.5x² - 9.5x + 2.5

Додаємо остачу -4.5x² + 8.5x + 1.5 і отримуємо 2x5 - 3x4 + 5x² - x + 4, тобто ділене Pm.
