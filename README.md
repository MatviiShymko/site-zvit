# Лабораторні роботи з дисципліни «Основи програмування»

Шимко Матвій Анатолійович, група ІПЗ-11(3), номер у списку 30.
Київський національний університет імені Тараса Шевченка, факультет
інформаційних технологій, кафедра програмних систем і технологій.

Звіти оформлено як сайт: відкрийте `index.html` у браузері.

## Структура

| Тека | Лабораторна робота |
|---|---|
| `lab01` | Арифметичні вирази та розв'язання математичних задач мовою C++ |
| `lab02` | Розгалужені обчислювальні процеси та логічні оператори |
| `lab03` | Циклічні обчислювальні процеси |
| `lab04` | Рекурентні співвідношення. Степеневі ряди. Ланцюгові дроби |
| `lab05` | Рекурсивні функції |
| `lab06` | Одновимірні масиви |
| `lab07` | Багатовимірні масиви |
| `lab08` | Покажчики та посилання. Покажчики на функції |
| `lab09` | Обробка рядків |
| `lab10` | Структури, масиви структур та об'єднання |
| `lab11` | Текстові та бінарні файли |

У кожній теці:
- `index.html`: звіт;
- `task*.cpp`: тексти програм;
- `img/`: блок-схеми та результати виконання.

## Компіляція

Кожна програма займає один файл (стандарт C++17):

```
g++ -std=c++17 -Wall lab03/task1.cpp -o task1
./task1
```
