2. Умови задач

Варіант 6 (у таблиці 24 варіанти, 30 - 24 = 6).

Завдання 1 - варіант 6

Створити квадратну матрицю, розмірність якої n ≥ 3 ввести з клавіатури. Передбачити меню вибору способу створення матриці: введення з клавіатури або генерація псевдовипадкових додатних та від'ємних чисел. У створеній квадратній матриці визначити максимальний та мінімальний елементи та їх індекси. Поміняти місцями рядки, що містять максимальний та мінімальний елементи.

Якщо максимальний та мінімальний елементи знаходяться в одному стовпчику матриці, то визначити суму елементів цього стовпчика, інакше визначити суму елементів, що розташовані над головною діагоналлю. Надрукувати вхідну матрицю у вигляді таблиці, максимальний та мінімальний елементи та їх індекси, матрицю після переміни місцями рядків, шукані суми.

Загальні вимоги до завдання: передбачити вибір способу створення матриці; заборонено використовувати бібліотеку стандартних шаблонів STL, шаблон вектору std::vector, ітератори, контейнери, бібліотеки для роботи з матрицями.

Завдання 2 - варіант 6

Знайти суму та різницю двох матриць A, B однакової вимірності. Перевірити матриці на рівність. Вимірності матриць A, B увести з клавіатури. Перевірити можливість виконати операції додавання та віднімання матриць. У випадку, коли вимірності матриць різні, вивести відповідне повідомлення. Для вибору способу створення матриць використовувати меню: введення значень елементів матриці з клавіатури або генерація псевдовипадкових чисел в заданому з клавіатури діапазоні значень. Вивести на екран вхідні матриці та результати їх суми, різниці та перевірки на рівність.

Загальні вимоги до завдання:

  • передбачити вибір способу створення матриць;
  • передбачити вибір режиму виведення результатів: або тільки кінцевий результат, або з проміжними ітераціями;
  • заборонено використовувати STL, шаблон вектору, ітератори, контейнери, бібліотеки для роботи з матрицями.

В обох завданнях застосування покажчиків, динамічних масивів, операторів new і delete не схвалюється, тому в програмах їх немає.

3. Аналіз задач

Спільне для обох завдань

Матриця зберігається у двовимірному масиві, обидва індекси рахуються від нуля.

Динамічні масиви в цій роботі не схвалюються, тому матриці оголошено із запасом на 10 рядків і 10 стовпчиків. Елементи мають тип int, значення з клавіатури лежать від -1000 до 1000.

Усі цілі числа вводить функція inputNumber(minValue, maxValue). Якщо введено не число або число поза межами, значення вводиться ще раз. Через неї ж вводиться пункт меню, а саме меню зроблено оператором switch.

Завдання 1 - варіант 6

Спочатку максимум і мінімум дорівнюють a00, далі кожен елемент порівнюється з ними. Порівняння строгі, тому якщо таких елементів кілька, береться перший під час проходу по рядках.

Рядки міняються місцями в циклі по стовпчиках, через тимчасову змінну. Якщо максимум і мінімум в одному рядку, рядки не міняються, і програма повідомляє про це.

Умова не каже, для якої матриці рахувати суму, до перестановки чи після. У завданні спочатку йде перестановка, тому сума рахується для матриці після неї. Для суми над головною діагоналлю це важливо: у сценарії 1 вона дорівнює 4 до перестановки і 11 після.

Номери стовпчиків після перестановки рядків не змінюються, тому знайдені індекси підходять і далі. Над головною діагоналлю лежать елементи, для яких j > i, тому внутрішній цикл починається з j = i + 1. Якщо всі елементи однакові, максимумом і мінімумом є той самий елемент a00, рядки не міняються, а сума рахується для стовпчика 0.

Псевдовипадкові числа беруться від -99 до 99, щоб у матриці були додатні й від'ємні значення.

Завдання 2 - варіант 6

Сума й різниця двох матриць однакової вимірності обчислюються поелементно:

Sij = Aij + Bij,    Dij = Aij - Bij

Для перевірки на рівність програма рахує кількість пар різних елементів. Якщо вона дорівнює нулю, матриці рівні.

Спочатку вводяться вимірності A і B. Якщо вони різні, програма виводить повідомлення і завершує роботу, елементи матриць не вводяться.

Спосіб створення обирається один раз для обох матриць. Для генерації вводяться нижня і верхня межі, верхня не може бути меншою за нижню.

Користувач обирає режим виведення: лише кінцевий результат або проміжні ітерації. У другому режимі програма друкує кожен крок обчислення суми й різниці, а також кожну пару елементів під час порівняння і кількість різних елементів на цей момент.

5. Тексти програм

Завдання 1 - варіант 6

Файл task1.cpp

/////////////////////////////////////////////////////////////////////
// Ім'я файлу: task1.cpp
// Автор: Шимко Матвій, гр. ІПЗ-11(3)
// Номер версії модуля: version 1
// Запланована ціль: лабораторна робота №7, завдання 1, варіант 6.
//                   Знайти максимальний і мінімальний елементи квадратної
//                   матриці, поміняти місцями їхні рядки, обчислити суму.
/////////////////////////////////////////////////////////////////////

#include <cstdlib>
#include <ctime>
#include <iomanip>
#include <iostream>
using namespace std;

//=========== константи
const int MIN_SIZE = 3;      // найменша розмірність матриці
const int MAX_SIZE = 10;     // найбільша розмірність матриці
const int MIN_VALUE = -1000; // межі елемента, що вводиться з клавіатури
const int MAX_VALUE = 1000;
const int RANDOM_LIMIT = 99; // випадкові числа від -99 до 99
const int CELL_WIDTH = 7;    // ширина стовпчика під час виведення

//=========== глобальні змінні
int matrix[MAX_SIZE][MAX_SIZE] = {{0}}; // квадратна матриця
int matrixSize = 0;                     // розмірність матриці
int choice = 0;                         // вибраний пункт меню
int maximum = 0;                        // максимальний елемент
int maxRow = 0;                         // його рядок
int maxColumn = 0;                      // його стовпчик
int minimum = 0;                        // мінімальний елемент
int minRow = 0;                         // його рядок
int minColumn = 0;                      // його стовпчик
int sum = 0;                            // шукана сума

/*
 * Функція виводить дані про автора та умову задачі
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void welcome()
{
    cout << "Lab work 7. Task 1. Variant 6." << endl;
    cout << "Author: Matvii Shimko, group IPZ-11(3)" << endl << endl;

    cout << "Find the maximum and minimum of a square matrix and swap their"
         << endl;
    cout << "rows. If they are in one column, find the sum of this column,"
         << endl;
    cout << "otherwise the sum of the elements above the main diagonal." << endl
         << endl;
}

/*
 * Функція вводить ціле число. Якщо введено не число або число поза
 * межами, введення повторюється
 * Параметри: minValue, maxValue - межі допустимого значення
 * Значення, що повертаються: введене число
 */
int inputNumber(int minValue, int maxValue)
{
    int number = 0;

    cin >> number;
    while (cin.fail() || number < minValue || number > maxValue)
    {
        cin.clear();            // скинути помилку введення
        cin.ignore(1000, '\n'); // і пропустити неправильний рядок
        cout << "Error! Enter a number from " << minValue << " to " << maxValue
             << ": ";
        cin >> number;
    }

    return number;
}

/*
 * Функція вводить розмірність матриці
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void inputSize()
{
    cout << "Enter the matrix size n (from " << MIN_SIZE << " to " << MAX_SIZE
         << "): ";
    matrixSize = inputNumber(MIN_SIZE, MAX_SIZE);
}

/*
 * Функція вводить елементи матриці з клавіатури
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void inputMatrix()
{
    for (int i = 0; i < matrixSize; i++)
    {
        for (int j = 0; j < matrixSize; j++)
        {
            cout << "Enter the element [" << i << "][" << j << "]: ";
            matrix[i][j] = inputNumber(MIN_VALUE, MAX_VALUE);
        }
    }
}

/*
 * Функція заповнює матрицю псевдовипадковими числами від -99 до 99
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void generateMatrix()
{
    srand(time(NULL));
    for (int i = 0; i < matrixSize; i++)
    {
        for (int j = 0; j < matrixSize; j++)
        {
            matrix[i][j] = rand() % (2 * RANDOM_LIMIT + 1) - RANDOM_LIMIT;
        }
    }
}

/*
 * Функція виводить меню і створює матрицю вибраним способом
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void runMenu()
{
    cout << endl << "How to create the matrix:" << endl;
    cout << "1 - enter from the keyboard" << endl;
    cout << "2 - fill with pseudorandom numbers" << endl;
    cout << "Your choice: ";
    choice = inputNumber(1, 2);

    switch (choice)
    {
        case 1 : inputMatrix(); break;
        case 2 : generateMatrix(); break;
        default : cout << "There is no such menu item." << endl; break;
    }
}

/*
 * Функція виводить матрицю у вигляді таблиці
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void printMatrix()
{
    for (int i = 0; i < matrixSize; i++)
    {
        for (int j = 0; j < matrixSize; j++)
        {
            cout << setw(CELL_WIDTH) << matrix[i][j];
        }
        cout << endl;
    }
}

/*
 * Функція виводить вхідну матрицю, знаходить максимальний і мінімальний
 * елементи та їх індекси. Якщо таких елементів кілька, береться перший
 * під час проходу по рядках
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void findExtremes()
{
    cout << endl << "Input matrix:" << endl;
    printMatrix();

    maximum = matrix[0][0];
    minimum = matrix[0][0];

    for (int i = 0; i < matrixSize; i++)
    {
        for (int j = 0; j < matrixSize; j++)
        {
            if (matrix[i][j] > maximum)
            {
                maximum = matrix[i][j];
                maxRow = i;
                maxColumn = j;
            }
            if (matrix[i][j] < minimum)
            {
                minimum = matrix[i][j];
                minRow = i;
                minColumn = j;
            }
        }
    }

    cout << endl
         << "Maximum = " << maximum << ", row " << maxRow << ", column "
         << maxColumn << endl;
    cout << "Minimum = " << minimum << ", row " << minRow << ", column "
         << minColumn << endl;
}

/*
 * Функція міняє місцями рядки з максимальним і мінімальним елементами.
 * Якщо це один рядок, матриця не змінюється
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void swapRows()
{
    int temporary = 0;

    if (maxRow == minRow)
    {
        cout << endl
             << "Maximum and minimum are in the same row, "
             << "there is nothing to swap." << endl;
    }
    else
    {
        for (int j = 0; j < matrixSize; j++)
        {
            temporary = matrix[maxRow][j];
            matrix[maxRow][j] = matrix[minRow][j];
            matrix[minRow][j] = temporary;
        }
        cout << endl
             << "Rows " << maxRow << " and " << minRow << " are swapped."
             << endl;
    }

    cout << endl << "Output matrix:" << endl;
    printMatrix();
}

/*
 * Функція рахує суму для матриці після перестановки: суму стовпчика, якщо
 * максимальний і мінімальний елементи в ньому обидва, інакше суму
 * елементів над головною діагоналлю
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void calculateSum()
{
    sum = 0;

    if (maxColumn == minColumn)
    {
        for (int i = 0; i < matrixSize; i++)
        {
            sum = sum + matrix[i][maxColumn];
        }
        cout << endl << "Maximum and minimum are in the same column." << endl;
        cout << "Sum of column " << maxColumn << " = " << sum << endl;
    }
    else
    {
        for (int i = 0; i < matrixSize; i++)
        {
            for (int j = i + 1; j < matrixSize; j++)
            {
                sum = sum + matrix[i][j];
            }
        }
        cout << endl << "Maximum and minimum are in different columns." << endl;
        cout << "Sum of the elements above the main diagonal = " << sum << endl;
    }
}

int main()
{
    welcome();
    inputSize();
    runMenu();
    findExtremes();
    swapRows();
    calculateSum();
    return 0;
}

int rowsB = 0; // вимірність матриці B
int columnsB = 0;

bool isDetailed = false; // чи виводити проміжні ітерації
int lowerBound = 0;      // межі випадкових чисел
int upperBound = 0;
int differentCount = 0; // скільки елементів не збігаються

/*
 * Функція виводить дані про автора та умову задачі
 * Параметри: немає
 * Значення, що повертаються: немає

void welcome()
{

}

/*
 * Функція вводить ціле число. Якщо введено не число або число поза
 * межами, введення повторюється
 * Параметри: minValue, maxValue - межі допустимого значення
 * Значення, що повертаються: введене число
 */
int inputNumber(int minValue, int maxValue)
{
    int number = 0;

    cin >> number;
    while (cin.fail() || number < minValue || number > maxValue)
    {
        cin.clear();            // скинути помилку введення
        cin.ignore(1000, '\n'); // і пропустити неправильний рядок
        cout << "Error! Enter a number from " << minValue << " to " << maxValue
             << ": ";
        cin >> number;
    }

    return number;
}

/*
 * Функція вводить вимірності обох матриць
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void inputSizes()
{
    cout << "Enter the rows of A (from 1 to " << MAX_SIZE << "): ";
    rowsA = inputNumber(1, MAX_SIZE);
    cout << "Enter the columns of A (from 1 to " << MAX_SIZE << "): ";
    columnsA = inputNumber(1, MAX_SIZE);
    cout << "Enter the rows of B (from 1 to " << MAX_SIZE << "): ";
    rowsB = inputNumber(1, MAX_SIZE);
    cout << "Enter the columns of B (from 1 to " << MAX_SIZE << "): ";
    columnsB = inputNumber(1, MAX_SIZE);
}

/*
 * Функція вводить елементи матриці з клавіатури
 * Параметри: matrix - матриця, name - її назва для підказки
 * Значення, що повертаються: немає
 */
void inputMatrix(int matrix[MAX_SIZE][MAX_SIZE], char name)
{
    for (int i = 0; i < rowsA; i++)
    {
        for (int j = 0; j < columnsA; j++)
        {
            cout << "Enter " << name << "[" << i << "][" << j << "]: ";
            matrix[i][j] = inputNumber(MIN_VALUE, MAX_VALUE);
        }
    }
}

/*
 * Функція вводить діапазон псевдовипадкових чисел
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void inputRange()
{
    srand(time(NULL)); // запустити генератор один раз, перед генерацією

    cout << "Enter the lower bound (from " << MIN_VALUE << " to " << MAX_VALUE
         << "): ";
    lowerBound = inputNumber(MIN_VALUE, MAX_VALUE);
    cout << "Enter the upper bound (from " << lowerBound << " to " << MAX_VALUE
         << "): ";
    upperBound = inputNumber(lowerBound, MAX_VALUE);
}

/*
 * Функція заповнює матрицю псевдовипадковими числами з діапазону
 * Параметри: matrix - матриця, яку заповнюємо
 * Значення, що повертаються: немає
 */
void generateMatrix(int matrix[MAX_SIZE][MAX_SIZE])
{
    for (int i = 0; i < rowsA; i++)
    {
        for (int j = 0; j < columnsA; j++)
        {
            matrix[i][j] = rand() % (upperBound - lowerBound + 1) + lowerBound;
        }
    }
}

/*
 * Функція виводить меню і створює матриці вибраним способом
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void runMenu()
{
    cout << endl << "How to create the matrices:" << endl;
    cout << "1 - enter from the keyboard" << endl;
    cout << "2 - fill with pseudorandom numbers in a given range" << endl;
    cout << "Your choice: ";
    choice = inputNumber(1, 2);

    switch (choice)
    {
        case 1 :
            inputMatrix(matrixA, 'A');
            inputMatrix(matrixB, 'B');
            break;
        case 2 :
            inputRange();
            generateMatrix(matrixA);
            generateMatrix(matrixB);
            break;
        default : cout << "There is no such menu item." << endl; break;
    }
}

/*
 * Функція вводить режим виведення результатів
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void inputOutputMode()

    cout << endl << "Output mode:" << endl;
    cout << "1 - only the final result" << endl;
    cout << "2 - with intermediate iterations" << endl;
    cout << "Your choice: ";
    choice = inputNumber(1, 2);
    if (choice == 2)

        isDetailed = true;
    }
}

/*
 * Функція виводить матрицю у вигляді таблиці
 * Параметри: matrix - матриця, яку виводимо
 * Значення, що повертаються: немає
 */
void printMatrix(int matrix[MAX_SIZE][MAX_SIZE])
{
    for (int i = 0; i < rowsA; i++)
    {
        for (int j = 0; j < columnsA; j++)
        {
            cout << setw(CELL_WIDTH) << matrix[i][j];
        }
        cout << endl;
    }
}

/*
 * Функція обчислює суму матриць
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void calculateSum()
{
    cout << endl;
    for (int i = 0; i < rowsA; i++)
    {
        for (int j = 0; j < columnsA; j++)
        {
            matrixSum[i][j] = matrixA[i][j] + matrixB[i][j];
            if (isDetailed)
            {
                cout << "S[" << i << "][" << j << "] = " << matrixA[i][j]
                     << " + " << matrixB[i][j] << " = " << matrixSum[i][j]
                     << endl;
            }
        }
    }

    cout << "Sum A + B:" << endl;
    printMatrix(matrixSum);
}

/*
 * Функція обчислює різницю матриць
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void calculateDifference()
{
    cout << endl;
    for (int i = 0; i < rowsA; i++)
    {
        for (int j = 0; j < columnsA; j++)
        {
            matrixDifference[i][j] = matrixA[i][j] - matrixB[i][j];
            if (isDetailed)
            {
                cout << "D[" << i << "][" << j << "] = " << matrixA[i][j]
                     << " - " << matrixB[i][j] << " = "
                     << matrixDifference[i][j] << endl;
            }
        }
    }

    cout << "Difference A - B:" << endl;
    printMatrix(matrixDifference);
}

/*
 * Функція порівнює матриці поелементно. Матриці рівні, якщо немає
 * жодної пари різних елементів
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void compareMatrices()
{
    cout << endl;
    differentCount = 0;

    for (int i = 0; i < rowsA; i++)
    {
        for (int j = 0; j < columnsA; j++)
        {
            if (matrixA[i][j] != matrixB[i][j])
            {
                differentCount++;
            }
            if (isDetailed)
            {
                cout << "A[" << i << "][" << j << "] = " << matrixA[i][j]
                     << ", B[" << i << "][" << j << "] = " << matrixB[i][j]
                     << ", different so far: " << differentCount << endl;
            }
        }
    }

    if (differentCount == 0)
    {
        cout << "The matrices are equal." << endl;
    }
    else
    {
        cout << "The matrices are not equal, different elements: "
             << differentCount << endl;
    }
}

/*
 * Функція виконує операції, якщо вимірності однакові, інакше
 * виводить повідомлення
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void processMatrices()
{
    if (rowsA != rowsB || columnsA != columnsB)
    {
        cout << endl
             << "The dimensions are different: " << rowsA << " x " << columnsA
             << " and " << rowsB << " x " << columnsB << "." << endl;
        cout << "The sum and the difference cannot be found, "
             << "and the matrices are not equal." << endl;
    }
    else
    {
        runMenu();
        inputOutputMode();

        cout << endl << "Matrix A:" << endl;
        printMatrix(matrixA);
        cout << "Matrix B:" << endl;
        printMatrix(matrixB);

        calculateSum();
        calculateDifference();
        compareMatrices();
    }
}

int main()
{
    welcome();
    inputSizes();
    processMatrices();
    return 0;
}
