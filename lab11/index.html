2. Умови задач

Завдання 1 - варіант 6.1

Варіант 6 (у таблиці 24 варіанти, 30 - 24 = 6).

Увести рядки з клавіатури і записати їх у текстовий файл. Визначити:

  • кількість рядків файла;
  • максимальну довжину рядка;
  • кількість порожніх рядків;
  • рядок, що починається та завершується заданими користувачем символами.

Отримані значення записати у новий текстовий файл.

Вимоги до завдання 1:

  • код складається з функцій, основна програма викликає їх залежно від вибору команд меню;
  • меню команд виконує окремі операції з обробки файлу;
  • програма створює текстовий файл шляхом введення даних з клавіатури і виводить вміст файлу на екран;
  • у кожній функції відкривати вхідні файли та закривати вихідні;
  • обробку рядків здійснювати в окремих функціях, використовувати тільки бібліотеку string.h;
  • STL, методи класу string й ітератори використовувати заборонено.

Завдання 2 - варіант 5.2

Завдання 2 продовжує програму лабораторної роботи №10, а вона виконана за варіантом 5 (у таблиці 25 варіантів, 30 - 25 = 5). Тому тут варіант 5.2.

Створити масив структур. Кожна структура складається з таких елементів: місто, інститут, факультет, список спеціальностей, план прийому на перший курс. Створений масив структур записати до бінарного файла. Виконати такі операції з бінарним файлом:

  • доповнити бінарний файл новими записами;
  • замінити вибраний користувачем запис у бінарному файлі на новий, значення полів якого ввести з клавіатури;
  • видалити з бінарного файлу вибраний користувачем запис.

Здійснити пошук у бінарному файлі та вивести у вигляді таблиць:

  • список спеціальностей, що містять у своїй назві слова "комп'ютерний" або "автоматизований";
  • факультети й інститути, де є задана спеціальність;
  • факультет, інститут і місто, де на вказану користувачем спеціальність виділено найбільше місць.

Вимоги до завдання 2:

  • створений масив структур записати до бінарного файлу;
  • надрукувати масив структур у вигляді таблиці, зчитавши дані з бінарного файлу;
  • результати запитів записати до нового бінарного файлу і вивести на екран;
  • розробити функції додавання нових даних, видалення даних і заміни значень у бінарному файлі на вимогу користувача.

3. Аналіз задач

Завдання 1 - варіант 6.1

У цьому завданні файли обробляються класами потоків ifstream і ofstream. Рядки зберігаються у файлі lines.txt, результати у файлі result.txt.

Спочатку вводиться кількість рядків від 1 до 20, потім самі рядки через cin.getline. Кількість потрібна, бо рядок може бути порожнім. Рядок, довший за 255 символів, програма просить увести ще раз.

Кожну характеристику рахує окрема функція, яка сама відкриває файл, читає його по рядках і закриває. Довжина рядка визначається через strlen. Функція processFile записує ці значення у файл результатів, а потім переглядає файл ще раз і дописує рядки, які починаються і завершуються заданими символами. Таких рядків може бути кілька, тому записуються всі та їх кількість. Символи порівнюються з урахуванням регістру.

Якщо файлу немає, програма виводить повідомлення, і дія не виконується. Порожній файл теж не обробляється. Літери замість числа й число поза межами обробляються через cin.fail(), введення повторюється. Номер, якого немає в меню, обробляє default.

Завдання 2 - варіант 5.2

Завдання 2 продовжує лабораторну роботу №10: структури Specialty і Faculty, створення масиву і таблиця лишилися такими самими. Файли обробляються функціями stdio.h: записи лежать у faculties.dat, результати запитів у results.dat. Рядки в записі є масивами символів, тому всі записи мають однаковий розмір 160 байтів (sizeof(Faculty)), і файл можна читати та змінювати цілими записами.

Пункт меню 4 записує весь масив у файл у режимі "wb", старий вміст файлу зникає. Пункт 5 читає записи з файлу і виводить таблицю, тому дані зберігаються між запусками програми.

Функція appendRecords відкриває файл у режимі "ab", і нові записи стають у кінець. Функція replaceRecord відкриває його в режимі "r+b", через fseek переходить на зміщення (номер - 1) · 160 байтів і пише новий запис поверх старого. Запис не можна просто прибрати з файлу, тому deleteRecord переписує всі записи, крім вибраного, у тимчасовий файл temp.dat, видаляє старий файл і дає тимчасовому його ім'я.

Кількість записів рахує countRecords за розміром файлу. Номер запису для заміни й видалення вводиться від 1 до цієї кількості.

Запити читають дані з файлу. Кожен знайдений рядок записується в results.dat як запис Faculty з однією спеціальністю, а потім цей файл друкує функція printFile. Запит 3 проходить файл двічі: спочатку шукає найбільший план, потім fseek повертає покажчик на початок, і в результат потрапляють рядки з таким планом. Ключі вводяться з клавіатури, великі й малі літери розрізняються.

Числа й рядки перевіряються так само, як у лабораторній роботі №10. Якщо файлу для читання немає (покажчик дорівнює NULL), програма виводить повідомлення, і дія не виконується.

5. Тексти програм

Завдання 1 - варіант 6.1

Файл task1.cpp

/////////////////////////////////////////////////////////////////////
// Ім'я файлу: task1.cpp
// Автор: Шимко Матвій, гр. ІПЗ-11(3)
// Номер версії модуля: version 2
// Запланована ціль: лабораторна робота №11, завдання 1, варіант 6.1.
//                   Записати рядки з клавіатури у текстовий файл,
//                   визначити його характеристики і записати їх
//                   у новий текстовий файл.
/////////////////////////////////////////////////////////////////////

#include <cstring>
#include <fstream>
#include <iostream>
using namespace std;

//=========== константи
const int MAX_LINES = 20;    // найбільша кількість рядків з клавіатури
const int LINE_LENGTH = 256; // розмір рядка разом із символом кінця рядка
const char TEXT_FILE[] = "lines.txt";    // текстовий файл
const char RESULT_FILE[] = "result.txt"; // новий файл результатів

//=========== глобальні змінні
ifstream inputFile;          // потік для читання файлу
ofstream outputFile;         // потік для запису файлу
char line[LINE_LENGTH] = ""; // поточний рядок

/*
 * Функція виводить дані про автора та умову задачі
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void welcome()
{
    cout << "Lab work 11. Task 1. Variant 6.1." << endl;
    cout << "Author: Matvii Shimko, group IPZ-11(3)" << endl << endl;

    cout << "Write lines from the keyboard to a text file. Find the number of"
         << endl;
    cout << "lines, the maximum length, the number of empty lines and the lines"
         << endl;
    cout << "with given first and last characters. Write it to a new file."
         << endl;
}

/*
 * Функція вводить рядки з клавіатури і записує їх у текстовий файл.
 * Рядок може бути порожнім
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void createFile()
{
    int count = 0; // кількість рядків

    outputFile.open(TEXT_FILE);
    if (!outputFile.is_open())
    {
        cout << "Error! Cannot open file " << TEXT_FILE << endl;
    }
    else
    {
        cout << "Enter number of lines (from 1 to " << MAX_LINES << "): ";
        cin >> count;
        while (cin.fail() || count < 1 || count > MAX_LINES)
        {
            cin.clear();            // скинути помилку введення
            cin.ignore(1000, '\n'); // і пропустити неправильний рядок
            cout << "Error! Enter a number from 1 to " << MAX_LINES << ": ";
            cin >> count;
        }
        cin.ignore(1000, '\n'); // прибрати кінець рядка перед cin.getline

        for (int i = 0; i < count; i++)
        {
            cout << "Enter line " << i + 1 << ": ";
            cin.getline(line, LINE_LENGTH);
            while (cin.fail())
            {
                cin.clear();            // скинути помилку введення
                cin.ignore(1000, '\n'); // і пропустити залишок рядка
                cout << "Error! The line is too long. Enter it again: ";
                cin.getline(line, LINE_LENGTH);
            }
            outputFile << line << endl;
        }
        outputFile.close();

        cout << "File " << TEXT_FILE << " is created." << endl;
    }
}

/*
 * Функція виводить вміст файлу на екран
 * Параметри: name - ім'я файлу
 * Значення, що повертаються: немає
 */
void showFile(const char name[])
{
    inputFile.open(name);
    if (!inputFile.is_open())
    {
        cout << "Error! File " << name << " does not exist." << endl;
    }
    else
    {
        cout << endl << "Contents of file " << name << ":" << endl;
        inputFile.getline(line, LINE_LENGTH);
        while (!inputFile.fail())
        {
            cout << line << endl;
            inputFile.getline(line, LINE_LENGTH);
        }
        inputFile.close();
    }
}

/*
 * Функція рахує рядки текстового файлу. Якщо файлу немає, читання
 * не вдається і кількість лишається 0
 * Параметри: немає
 * Значення, що повертаються: кількість рядків
 */
int countLines()
{
    int count = 0;

    inputFile.open(TEXT_FILE);
    inputFile.getline(line, LINE_LENGTH);
    while (!inputFile.fail())
    {
        count++;
        inputFile.getline(line, LINE_LENGTH);
    }
    inputFile.close();

    if (count == 0)
    {
        cout << "Error! File " << TEXT_FILE << " does not exist or is empty."
             << endl;
    }

    return count;
}

/*
 * Функція знаходить максимальну довжину рядка текстового файлу
 * Параметри: немає
 * Значення, що повертаються: максимальна довжина
 */
int findMaxLength()
{
    int maxLength = 0;
    int length = 0;

    inputFile.open(TEXT_FILE);
    inputFile.getline(line, LINE_LENGTH);
    while (!inputFile.fail())
    {
        length = strlen(line);
        if (length > maxLength)
        {
            maxLength = length;
        }
        inputFile.getline(line, LINE_LENGTH);
    }
    inputFile.close();

    return maxLength;
}

/*
 * Функція рахує порожні рядки текстового файлу
 * Параметри: немає
 * Значення, що повертаються: кількість порожніх рядків
 */
int countEmptyLines()
{
    int count = 0;

    inputFile.open(TEXT_FILE);
    inputFile.getline(line, LINE_LENGTH);
    while (!inputFile.fail())
    {
        if (strlen(line) == 0)
        {
            count++;
        }
        inputFile.getline(line, LINE_LENGTH);
    }
    inputFile.close();

    return count;
}

/*
 * Функція перевіряє, чи починається і чи завершується поточний рядок
 * заданими символами
 * Параметри: first, last - задані символи
 * Значення, що повертаються: true, якщо рядок підходить
 */
bool isMatchingLine(char first, char last)
{
    bool isMatching = false;
    int length = strlen(line);

    if (length > 0)
    {
        if (line[0] == first && line[length - 1] == last)
        {
            isMatching = true;
        }
    }

    return isMatching;
}

/*
 * Функція вводить задані символи і записує у новий текстовий файл
 * характеристики файлу та рядки, що починаються і завершуються цими
 * символами
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void processFile()
{
    char first = ' ';   // заданий символ на початку рядка
    char last = ' ';    // заданий символ у кінці рядка
    int matchCount = 0; // кількість рядків із заданими символами
    int lineCount = countLines();

    if (lineCount > 0)
    {
        outputFile.open(RESULT_FILE);
        if (!outputFile.is_open())
        {
            cout << "Error! Cannot open file " << RESULT_FILE << endl;
        }
        else
        {
            cout << "Enter first character of the line: ";
            cin >> first;
            cout << "Enter last character of the line: ";
            cin >> last;
            cin.ignore(1000, '\n'); // пропустити решту рядка

            outputFile << "Number of lines: " << lineCount << endl;
            outputFile << "Maximum line length: " << findMaxLength() << endl;
            outputFile << "Number of empty lines: " << countEmptyLines()
                       << endl;
            outputFile << "Lines that start with '" << first
                       << "' and end with '" << last << "':" << endl;

            inputFile.open(TEXT_FILE);
            inputFile.getline(line, LINE_LENGTH);
            while (!inputFile.fail())
            {
                if (isMatchingLine(first, last))
                {
                    outputFile << line << endl;
                    matchCount++;
                }
                inputFile.getline(line, LINE_LENGTH);
            }
            inputFile.close();

            outputFile << "Number of such lines: " << matchCount << endl;
            outputFile.close();
            cout << "Results are written to file " << RESULT_FILE << endl;
        }
    }
}

/*
 * Функція виводить меню і викликає вибрану дію, поки не вибрано вихід
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void runMenu()
{
    int choice = -1;

    while (choice != 0)
    {
        cout << endl << "Menu" << endl;
        cout << "1 - create text file from keyboard" << endl;
        cout << "2 - show text file" << endl;
        cout << "3 - process text file and write results" << endl;
        cout << "4 - show results file" << endl;
        cout << "0 - exit" << endl;
        cout << "Enter menu item: ";
        cin >> choice;
        while (cin.fail())
        {
            cin.clear();            // скинути помилку введення
            cin.ignore(1000, '\n'); // і пропустити неправильний рядок
            cout << "Error! Enter a number: ";
            cin >> choice;
        }
        cin.ignore(1000, '\n'); // прибрати кінець рядка перед cin.getline

        switch (choice)
        {
            case 1 : createFile(); break;
            case 2 : showFile(TEXT_FILE); break;
            case 3 : processFile(); break;
            case 4 : showFile(RESULT_FILE); break;
            case 0 : cout << "The program is finished." << endl; break;
            default : cout << "Error! There is no such menu item." << endl;
        }
    }
}

int main()
{
    welcome();
    runMenu();
    return 0;
}

//                   у бінарний файл, виконати запити за даними файлу,
//                   додавати, замінювати і видаляти записи файлу.

#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <ctime>
#include <iomanip>
#include <iostream>
using namespace std;

//=========== константи
const int MAX_RECORDS = 10;    // найбільша кількість записів масиву
const int MAX_SPECIALTIES = 3; // найбільша кількість спеціальностей у записі
const int CITY_LENGTH = 15;    // довжини рядків разом із символом кінця рядка,
const int INSTITUTE_LENGTH = 22; // вони ж ширини колонок таблиці
const int FACULTY_LENGTH = 22;
const int SPECIALTY_LENGTH = 27;
const int NUMBER_WIDTH = 4; // ширина колонки з номером
const int MAX_PLAN = 500;   // найбільший план прийому на спеціальність
const int CITY_TOTAL = 3;   // кількість назв для генерації
const int INSTITUTE_TOTAL = 2;
const int FACULTY_TOTAL = 2;
const int SPECIALTY_TOTAL = 4;
const char DATA_FILE[] = "faculties.dat"; // бінарний файл із записами
const char RESULT_FILE[] = "results.dat"; // новий файл результатів запиту
const char TEMP_FILE[] = "temp.dat";      // тимчасовий файл для видалення

// назви, з яких генератор випадкових чисел складає записи
const char CITIES[CITY_TOTAL][CITY_LENGTH] = {"Kyiv", "Lviv", "Odesa"};
const char INSTITUTES[INSTITUTE_TOTAL][INSTITUTE_LENGTH] = {
    "Polytechnic Institute", "State University"};
const char FACULTIES[FACULTY_TOTAL][FACULTY_LENGTH] = {"Informatics",
                                                       "Cybernetics"};
const char SPECIALTIES[SPECIALTY_TOTAL][SPECIALTY_LENGTH] = {
    "Computer Science", "Software Engineering", "Computer Engineering",
    "Automated Control Systems"};

// заголовок таблиці, колонки відповідають ширинам вище
const char TABLE_HEADER[] = "No  City           Institute             "
                            "Faculty               Specialty                  "
                            "Plan";

//=========== структури
struct Specialty // спеціальність зі своїм планом прийому
{
    char name[SPECIALTY_LENGTH]; // назва спеціальності
    int plan;                    // план прийому на перший курс
};

struct Faculty // один запис масиву
{
    char city[CITY_LENGTH];                 // місто
    char institute[INSTITUTE_LENGTH];       // інститут
    char name[FACULTY_LENGTH];              // факультет
    Specialty specialties[MAX_SPECIALTIES]; // список спеціальностей
    int specialtyCount;                     // кількість спеціальностей
};

//=========== глобальні змінні
Faculty records[MAX_RECORDS] = {}; // масив структур
int recordCount = 0;               // кількість записів у масиві

/*
 * Функція виводить дані про автора та умову задачі

/*
 * Функція вводить ціле число із заданих меж. Якщо введено не число
 * або число поза межами, введення повторюється
 * Параметри: minValue, maxValue - межі числа
 * Значення, що повертаються: введене число
 */
int inputNumber(int minValue, int maxValue)
{
    int number = 0;

    cin >> number;
    while (cin.fail() || number < minValue || number > maxValue)
    {
        cin.clear();            // скинути помилку введення
        cin.ignore(1000, '\n'); // і пропустити неправильний рядок
        cout << "Error! Enter a number from " << minValue << " to " << maxValue
             << ": ";
        cin >> number;
    }
    cin.ignore(1000, '\n'); // прибрати кінець рядка перед cin.getline

    return number;
}

/*
 * Функція вводить непорожній рядок. Якщо рядок порожній або задовгий,
 * введення повторюється
 * Параметри: text - куди записати рядок; maxLength - розмір масиву text
 * Значення, що повертаються: немає
 */
void inputText(char* text, int maxLength)
{
    cin.getline(text, maxLength);
    while (cin.fail() || strlen(text) == 0)
    {
        if (cin.fail())
        {
            cin.clear();            // скинути помилку введення
            cin.ignore(1000, '\n'); // і пропустити залишок рядка
        }
        cout << "Error! Enter text, maximum length is " << maxLength - 1
             << ": ";
        cin.getline(text, maxLength);
    }
}

/*
 * Функція вводить з клавіатури один запис
 * Параметри: немає
 * Значення, що повертаються: заповнена структура
 */
Faculty inputRecord()
{
    Faculty record = {};

    cout << "Enter city: ";
    inputText(record.city, CITY_LENGTH);
    cout << "Enter institute: ";
    inputText(record.institute, INSTITUTE_LENGTH);
    cout << "Enter faculty: ";
    inputText(record.name, FACULTY_LENGTH);

    cout << "Enter number of specialties (from 1 to " << MAX_SPECIALTIES
         << "): ";
    record.specialtyCount = inputNumber(1, MAX_SPECIALTIES);
    for (int i = 0; i < record.specialtyCount; i++)
    {
        cout << "Enter specialty " << i + 1 << ": ";
        inputText(record.specialties[i].name, SPECIALTY_LENGTH);
        cout << "Enter plan (from 1 to " << MAX_PLAN << "): ";
        record.specialties[i].plan = inputNumber(1, MAX_PLAN);
    }

    return record;
}

/*
 * Функція складає один запис із випадкових назв і чисел. Спеціальності
 * беруться зі списку поспіль, тому в записі вони не повторюються
 * Параметри: немає
 * Значення, що повертаються: заповнена структура
 */
Faculty generateRecord()
{
    Faculty record = {};
    int firstIndex = rand() % SPECIALTY_TOTAL; // перша спеціальність запису

    strcpy(record.city, CITIES[rand() % CITY_TOTAL]);
    strcpy(record.institute, INSTITUTES[rand() % INSTITUTE_TOTAL]);
    strcpy(record.name, FACULTIES[rand() % FACULTY_TOTAL]);

    record.specialtyCount = MAX_SPECIALTIES;
    for (int i = 0; i < record.specialtyCount; i++)
    {
        strcpy(record.specialties[i].name,
               SPECIALTIES[(firstIndex + i) % SPECIALTY_TOTAL]);
        record.specialties[i].plan = 1 + rand() % MAX_PLAN;
    }

    return record;
}

/*
 * Функція виводить рядок таблиці: запис з однією його спеціальністю
 * Параметри: record - покажчик на запис; index - номер спеціальності;
 *            number - номер у таблиці
 * Значення, що повертаються: немає
 */
void printRow(Faculty* record, int index, int number)
{
    cout << left << setw(NUMBER_WIDTH) << number << setw(CITY_LENGTH)
         << record->city << setw(INSTITUTE_LENGTH) << record->institute
         << setw(FACULTY_LENGTH) << record->name << setw(SPECIALTY_LENGTH)
         << record->specialties[index].name << record->specialties[index].plan
         << endl;
}

/*
 * Функція виводить масив структур таблицею
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void printArray()
{
    cout << endl << TABLE_HEADER << endl;
    for (int i = 0; i < recordCount; i++)
    {
        for (int j = 0; j < records[i].specialtyCount; j++)
        {
            printRow(&records[i], j, i + 1);
        }
    }
}

/*
 * Функція створює масив і виводить його таблицею
 * Параметри: isRandom - true для генерації, false для введення з клавіатури
 * Значення, що повертаються: немає
 */
void createArray(bool isRandom)
{
    cout << "Enter number of records (from 1 to " << MAX_RECORDS << "): ";
    recordCount = inputNumber(1, MAX_RECORDS);

    for (int i = 0; i < recordCount; i++)
    {
        if (isRandom)
        {
            records[i] = generateRecord();
        }
        else
        {
            cout << "Record " << i + 1 << endl;
            records[i] = inputRecord();
        }
    }

    printArray();
}

/*
 * Функція записує масив у бінарний файл, старий вміст файлу зникає
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void writeArray()
{
    FILE* file = fopen(DATA_FILE, "wb");

    if (file == NULL)
    {
        cout << "Error! Cannot open file " << DATA_FILE << endl;
    }
    else
    {
        fwrite(records, sizeof(Faculty), recordCount, file);
        fclose(file);
        cout << "Records written to file: " << recordCount << endl;
    }
}

/*
 * Функція читає бінарний файл і виводить його записи таблицею
 * Параметри: name - ім'я файлу
 * Значення, що повертаються: немає
 */
void printFile(const char name[])
{
    Faculty record;
    int number = 0; // номер запису в таблиці
    FILE* file = fopen(name, "rb");

    if (file == NULL)
    {
        cout << "Error! File " << name << " does not exist." << endl;
    }
    else
    {
        cout << endl << TABLE_HEADER << endl;
        while (fread(&record, sizeof(Faculty), 1, file) == 1)
        {
            number++;
            for (int j = 0; j < record.specialtyCount; j++)
            {
                printRow(&record, j, number);
            }
        }
        fclose(file);

        if (number == 0)
        {
            cout << "File " << name << " has no records." << endl;
        }
    }
}

/*
 * Функція рахує записи у файлі за його розміром. Якщо файлу немає
 * або в ньому немає записів, виводить повідомлення
 * Параметри: немає
 * Значення, що повертаються: кількість записів
 */
int countRecords()
{
    int total = 0;
    FILE* file = fopen(DATA_FILE, "rb");

    if (file != NULL)
    {
        fseek(file, 0, SEEK_END);
        total = ftell(file) / sizeof(Faculty);
        fclose(file);
    }

    if (total == 0)
    {
        cout << "Error! File " << DATA_FILE
             << " does not exist or has no records." << endl;
    }

    return total;
}

/*
 * Функція дописує нові записи в кінець бінарного файлу
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void appendRecords()
{
    Faculty record;
    int count = 0; // кількість нових записів
    FILE* file = fopen(DATA_FILE, "ab");

    if (file == NULL)
    {
        cout << "Error! Cannot open file " << DATA_FILE << endl;
    }
    else
    {
        cout << "Enter number of new records (from 1 to " << MAX_RECORDS
             << "): ";
        count = inputNumber(1, MAX_RECORDS);

        for (int i = 0; i < count; i++)
        {
            cout << "New record " << i + 1 << endl;
            record = inputRecord();
            fwrite(&record, sizeof(Faculty), 1, file);
        }

        fclose(file);
        cout << "Records added to file: " << count << endl;
    }
}

/*
 * Функція замінює вибраний запис файлу на новий, введений з клавіатури
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void replaceRecord()
{
    Faculty record;
    FILE* file = NULL;
    int total = countRecords(); // кількість записів у файлі
    int number = 0;             // номер вибраного запису

    if (total > 0)
    {
        file = fopen(DATA_FILE, "r+b");
        if (file == NULL)
        {
            cout << "Error! Cannot open file " << DATA_FILE << endl;
        }
        else
        {
            cout << "Enter record number (from 1 to " << total << "): ";
            number = inputNumber(1, total);
            record = inputRecord();

            // перейти на початок вибраного запису і записати поверх нього
            fseek(file, (number - 1) * sizeof(Faculty), SEEK_SET);
            fwrite(&record, sizeof(Faculty), 1, file);
            fclose(file);
            cout << "Record " << number << " is replaced." << endl;
        }
    }
}

/*
 * Функція видаляє вибраний запис: переписує решту записів у тимчасовий
 * файл, який потім займає місце старого
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void deleteRecord()
{
    Faculty record;
    FILE* file = NULL;
    FILE* tempFile = NULL;
    int total = countRecords(); // кількість записів у файлі
    int number = 0;             // номер вибраного запису
    int current = 0;            // номер прочитаного запису

    if (total > 0)
    {
        tempFile = fopen(TEMP_FILE, "wb");
        if (tempFile == NULL)
        {
            cout << "Error! Cannot open file " << TEMP_FILE << endl;
        }
        else
        {
            cout << "Enter record number (from 1 to " << total << "): ";
            number = inputNumber(1, total);

            file = fopen(DATA_FILE, "rb");
            while (fread(&record, sizeof(Faculty), 1, file) == 1)
            {
                current++;
                if (current != number)
                {
                    fwrite(&record, sizeof(Faculty), 1, tempFile);
                }
            }
            fclose(file);
            fclose(tempFile);

            remove(DATA_FILE);
            rename(TEMP_FILE, DATA_FILE);
            cout << "Record " << number << " is deleted." << endl;
        }
    }
}

/*
 * Функція шукає у файлі спеціальності, у назвах яких є хоча б одне
 * з двох слів, записує результат у новий файл і виводить його
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void findByWords()
{
    Faculty record;
    Faculty result; // копія запису зі знайденою спеціальністю
    char firstWord[SPECIALTY_LENGTH] = "";
    char secondWord[SPECIALTY_LENGTH] = "";
    FILE* resultFile = NULL;
    FILE* file = fopen(DATA_FILE, "rb");

    if (file == NULL)
    {
        cout << "Error! File " << DATA_FILE << " does not exist." << endl;
    }
    else
    {
        resultFile = fopen(RESULT_FILE, "wb");
        if (resultFile == NULL)
        {
            cout << "Error! Cannot open file " << RESULT_FILE << endl;
        }
        else
        {
            cout << "Enter first word: ";
            inputText(firstWord, SPECIALTY_LENGTH);
            cout << "Enter second word: ";
            inputText(secondWord, SPECIALTY_LENGTH);

            while (fread(&record, sizeof(Faculty), 1, file) == 1)
            {
                for (int j = 0; j < record.specialtyCount; j++)
                {
                    if (strstr(record.specialties[j].name, firstWord) != NULL
                        || strstr(record.specialties[j].name, secondWord)
                               != NULL)
                    {
                        result = record;
                        result.specialties[0] = record.specialties[j];
                        result.specialtyCount = 1;
                        fwrite(&result, sizeof(Faculty), 1, resultFile);
                    }
                }
            }
            fclose(resultFile);
            printFile(RESULT_FILE);
        }
        fclose(file);
    }
}

/*
 * Функція знаходить у файлі найбільший план на задану спеціальність,
 * записує факультет, інститут і місто у новий файл і виводить його.
 * Якщо такий план є в кількох записах, у результат потрапляють усі
 * Параметри: немає
 * Значення, що повертаються: немає
 */
void findMaxPlan()
{
    Faculty record;
    Faculty result; // копія запису зі знайденою спеціальністю
    char specialty[SPECIALTY_LENGTH] = "";
    int maxPlan = 0; // найбільший план на спеціальність
    FILE* resultFile = NULL;
    FILE* file = fopen(DATA_FILE, "rb");

    if (file == NULL)
    {
        cout << "Error! File " << DATA_FILE << " does not exist." << endl;
    }
    else
    {
        resultFile = fopen(RESULT_FILE, "wb");
        if (resultFile == NULL)
        {
            cout << "Error! Cannot open file " << RESULT_FILE << endl;
        }
        else
        {
            cout << "Enter specialty: ";
            inputText(specialty, SPECIALTY_LENGTH);

            while (fread(&record, sizeof(Faculty), 1, file) == 1)
            {
                for (int j = 0; j < record.specialtyCount; j++)
                {
                    if (strcmp(record.specialties[j].name, specialty) == 0
                        && record.specialties[j].plan > maxPlan)
                    {
                        maxPlan = record.specialties[j].plan;
                    }
                }
            }

            fseek(file, 0, SEEK_SET); // другий прохід файлу з початку
            while (fread(&record, sizeof(Faculty), 1, file) == 1)
            {
                for (int j = 0; j < record.specialtyCount; j++)
                {
                    if (strcmp(record.specialties[j].name, specialty) == 0
                        && record.specialties[j].plan == maxPlan)
                    {
                        result = record;
                        result.specialties[0] = record.specialties[j];
                        result.specialtyCount = 1;
                        fwrite(&result, sizeof(Faculty), 1, resultFile);
                    }
                }
            }
            fclose(resultFile);
            printFile(RESULT_FILE);
        }
        fclose(file);
    }
}

Лабораторна робота №11 / 08 з 08

8. Висновки

Розроблено дві програми з меню: перша працює з текстовим файлом через класи потоків, друга з бінарним файлом через функції stdio.h. Перша записує рядки з клавіатури у файл, знаходить кількість рядків, найбільшу довжину, порожні рядки й рядки із заданими символами і записує це в новий файл.

Друга продовжує лабораторну роботу №10: масив структур зберігається в бінарному файлі, запити читають цей файл, а результат записують у новий. Записи можна додавати, замінювати і видаляти, після кожної такої операції перевірено таблицю і розмір файлу. Заміна виконується прямо у файлі через fseek, а для видалення потрібен тимчасовий файл.
